# GrindOS 🔥

A personal daily productivity app built with React + Vite.

## Features
- 🏠 Daily overview with progress tracking
- 🛡️ Skincare & hygiene routine tracker
- 💪 5-day workout split (gym + bodyweight)
- 📚 6-week study & career roadmap

## Tech Stack
- React 19
- Vite
- Deployed on GitHub Pages
